License texts for bundled components
====================================

These files are copied unmodified from the upstream package distributions.
THIRD_PARTY_NOTICES.txt (one folder up) names each component, its
copyright holder and license, and points here for the full text.

    cryptography\   LICENSE, LICENSE.APACHE, LICENSE.BSD
                    (Apache-2.0 OR BSD-3-Clause; upstream files as
                    distributed with cryptography 50.x)
    cffi\           LICENSE (MIT-0; cffi 2.1.1)
    pycparser\      LICENSE (BSD-3-Clause; pycparser 3.0)
    pyinstaller\    COPYING.txt (GPL-2.0-or-later with the bootloader
                    exception; PyInstaller 6.22.2)

The Spectral font license (SIL Open Font License 1.1) is inside the
application folder at assets\fonts\OFL.txt.
